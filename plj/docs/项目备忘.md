│   └── slam_perception

## 本地/远端边界

- `other/src/` 是本地自研 ROS 2 包目录；`other/third/` 是第三方源码 vendor 区，二者并列。
- 不把 `slam_frontend`、`slam_bringup`、`slam_perception` 复制进远端 `~/ros2_ws/src/` 或 `~/slam_ws/src/` 与第三方代码混编。
- 远端 `~/ros2_ws`、`~/slam_ws` 只视为参考/对照来源；本项目默认不依赖其中的现成包。
- 如果确定要用外部包，先 vendor 到本仓库根目录 `third/<package>`，再由本项目控制版本、补丁和编译。
- 未经用户在当前对话明确同意，不执行远端部署、上传、同步、push、创建 PR 或覆盖远端文件。
- 如需远端验证，先说明将要同步的路径、文件范围和命令，等待用户确认。

本机编译：

```bash
cd other
colcon build --symlink-install --base-paths src --packages-select slam_frontend slam_bringup slam_perception
```

引入 `third/` 内 ROS 包后，完整构建入口改为：

```bash
cd other
colcon build --symlink-install --base-paths src third
```

远端运行时默认只 source ROS 2 基础环境和本项目独立工作区；**不要**把本仓库包放进 `~/ros2_ws/src/` 与第三方源码混编。
