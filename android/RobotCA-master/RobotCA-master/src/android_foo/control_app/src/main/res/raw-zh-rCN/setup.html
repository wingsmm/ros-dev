配置

本应用通过 ROS Master 连接机器人。以下以 xtark 小车（ROS Melodic）为例说明常用配置步骤。

连接 xtark 真机

步骤 1：确认网络

手机或模拟器需与机器人在同一 Wi-Fi 网段。默认 Master URI 示例：

http://192.168.1.168:11311

步骤 2：在机器人端启动 ROS

在 Nano 上启动 roscore 及遥控所需节点（cmd_vel、激光、摄像头等）。可用项目脚本：

run_android_xtark.sh start

步骤 3：在应用中添加机器人

打开应用，点击右上角「+」添加机器人。填写：

  • 机器人名称：任意（支持中文）
  • Master URI：机器人 IP 与端口，如 http://192.168.1.168:11311

展开「显示高级选项」可修改各话题名称。xtark 默认话题：

  • 摇杆：/cmd_vel
  • 激光：/scan
  • 图像：/image_raw/compressed
  • 里程计：/odom
  • 位姿：/pose
  • GPS：/navsat/fix

步骤 4：连接

在机器人列表中点击名称或 Wi-Fi 图标即可连接。连接成功后将进入主控制界面。

使用仿真环境（可选）

若在 PC 上运行 Gazebo 等仿真，请确保仿真机与手机在同一局域网，将 Master URI 中的 localhost 替换为仿真机的局域网 IP 即可。
