## 已知坑（核查时别误判）

1. **远程 `ssh ... cmd &` 启节点不可靠**；应用脚本 + `nohup` / 桌面终端 / tmux。
2. **话题名是 `/vmware/depth/points`**，查错 topic 会以为点云没通。
3. **`base_link` 在这台车 TF 树不存在**；Fixed Frame 用 `base_link` 会让 TF/点云看起来断或漂。
4. **CameraInfo 时间戳可能比 depth 旧几秒**：默认只告警不丢帧（`CAMERA_INFO_MAX_AGE_S=0`）。
5. **Qt「深度增强」默认会启自己的 camera TF**：近场实验必须 `CAMERA_TF_ENABLE=0`，避免和 `camera_tf_guard` 抢边。
