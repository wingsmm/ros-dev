## 使用约定

- 复制最近一天的日志为新文件 `todo-YYYYMMDD.md` 再编辑，避免手写模板遗漏
- 每条只记录**已完成 + 已验收**的事项；未完成的另找地方跟踪，不塞到当日日志里
- 与各子仓文档（`android/docs/`、`pc/docs/`、`vmware/docs/`、`xtark/docs/`、`rk3568/docs/` 等）分工：
  - 本目录：**时间线**（谁在哪天做了什么）
  - 各子仓 `docs/`：**主题方案 / 说明**（架构、模块、协议等）
