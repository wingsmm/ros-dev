## 0. 关于 L1（L1_Overview）

### 0.1 简介

**Unitree 4D LiDAR L1** 是一款高性价比、安全可靠的 **4D 激光雷达**（**3D 位置 + 1D 灰度**），具备 **21 600 点/秒** 有效采样能力，适用于机器人、智慧城市、智能玩具、物流等场景，支持**建图、定位、识别、避障、环境扫描、3D 重建**等应用。

关键特性（官方口径）：

- **探测范围**：最近 **0.05 m**，最远 **30 m @90% 反射率**（RM 版；PM 版 20 m，详见 §7 参数规格）。
- **视场角**：水平 **360°** × 竖直 **90°**，覆盖上半球。
- **尺寸重量**：整机 **230 g**、**75 × 75 × 65 mm**。
- **内置 IMU**：3 轴加速度 + 3 轴陀螺仪，**250 Hz** 推送。
- **扫描频率**：周向 **11 Hz**，竖直 **180 Hz**，有效采样 **21 600 点/秒**。
- **工作温度**：**-10 ℃ ~ 60 ℃**。
- **人眼安全**：**IEC-60825 Class 1**（905 nm 脉冲）。

### 0.2 工作原理

L1 内部主要包括：**激光发射及测距核心、反光镜、高速旋转电机、低速旋转电机**。

- **高速电机**带动反光镜旋转，实现**竖直 180°** 扫描（180 Hz）。
- **低速电机**带动整个测量核心 **360° 水平旋转**（11 Hz）。
- 两轴复合形成 **360° × 90° 半球形 FOV**。

测距原理：**激光飞行时间（ToF）**。每次测距发射 **纳秒级窄脉冲红外激光**，接收反射光后由处理器解算距离与角度，通过 UART 输出。

供电与数据：4PIN 出线接**转接模块**，转接模块含 **12 V 供电口 + Type-C 数据口**，Type-C 接主机即可读取点云/IMU 数据。可自制线材替换转接模块以增强防护（详见 §2 接口定义）。

### 0.3 部件说明

| # | 部件 | 说明 |
|---|------|------|
| 1 | **光学窗口** | 激光光束的出射/入射口，视场角内的物体经此扫描；**必须定期清洁**，见 §0.5 保养。 |
| 2 | **出线口** | 4PIN 插头（GH1.25mm），配转接模块可快速接入；建议按线序自制适配线材以增强防尘防水，线序见 §2.2。 |
| 3 | **定位槽** | **4 个** 定位槽，设计固定支架时用于提高整机定位精度；具体尺寸见 §3.1 安装尺寸。 |
| 4 | **M3 安装孔** | **4 个** M3 螺纹孔（底部，深 6 mm），用于固定 L1；见 §3.1。 |

### 0.4 存储与运输

**存储（-20 ℃ ~ 60 ℃）**：

- 存放在**干燥、通风、无尘**环境。
- 避免与**腐蚀性 / 易燃 / 易爆**物品放置在一起。
- 轻拿轻放，避免损坏。
- 长期存储需**定期检查**。

**运输**：

- 装箱前**固定并确认安装到位**。
- 使用专用包装箱或缓冲材料。
- 运输过程避免**撞击、振动、摩擦**造成机械损坏。

### 0.5 保养（重点）

L1 正常使用时**仅需定期清洁光学窗口**：

1. 光学窗口如有灰尘、泥浆等污染会影响扫描数据质量。
2. 优先用**干净的清洁布轻轻擦拭**，力度要柔，**不要用力刮擦**以免损伤光学面。
3. 若仍有可视污点，用清洁布**蘸少量酒精**擦拭。

> 与 §0.3 呼应：光学窗口是 L1 唯一需要日常维护的部件；SDK 会输出 **脏污百分比 `Dirty Percentage`**（>10% 建议清洁，见 §1.4）。

## 1. 数据说明（L1_Overview_DATA）

### 1.1 通信与协议

- L1 经 **USB 串口** 与主机通信（经转接模块时，主机侧常见为 `ttyUSB*` / `ttyCH341USB*`）。
- 串口波特率默认 **2 000 000**（见 SDK `initialize()` 默认参数）。
- 原始数据按 **MavLink** 帧逐字节解析；SDK 内部完成解析并输出点云 / IMU。
- 若需自行从串口解析，参考 SDK 文档：
  `unitree_lidar_sdk/doc/HowToParsePointCloudAndIMUDataFromMavLinkMessages.md`

### 1.2 SDK 输出：点云

结构体 `PointUnitree` / `PointCloudUnitree`（`unitree_lidar_sdk.h`）：

| 字段 | 含义 |
|------|------|
| `x, y, z` | 直角坐标（米），在 `unilidar_lidar` 坐标系下 |
| `intensity` | 反射强度 |
| `time` | 相对点云时间戳的偏移 |
| `ring` | 线束 / 环号 |
| `stamp` | 点云时间戳（秒） |
| `id` | 帧序号 |

单次 `Scan` 最多 **120** 个有效点；`cloud_scan_num`（默认 **18**）表示累积多少线束后拼成一帧点云发布。

ROS2 发布为 `sensor_msgs/PointCloud2`，默认 topic / frame：

```text
topic:  unilidar/cloud
frame:  unilidar_lidar
```

本仓库实测点云约 **~9 Hz**（视 `cloud_scan_num` 与主机负载略有波动）。

### 1.3 SDK 输出：IMU

结构体 `IMUUnitree`：

| 字段 | 含义 |
|------|------|
| `quaternion[4]` | 姿态四元数 `[x, y, z, w]` |
| `angular_velocity[3]` | 角速度（rad/s） |
| `linear_acceleration[3]` | 线加速度 |
| `stamp`, `id` | 时间戳与序号 |

ROS2 发布为 `sensor_msgs/Imu`，默认：

```text
topic:  unilidar/imu
frame:  unilidar_imu
```

### 1.4 辅助数据（脏污、版本等）

- `example_lidar` 可读取 **脏污百分比**（`Dirty Percentage`）；官方示例中 **>10%** 会提示清洁保护罩。
- 可查询固件版本、SDK 版本（如 `lidar firmware version`、`lidar sdk version`）。
- 工作模式：`NORMAL`（正常测距）、`STANDBY`（待机）。
- 支持 LED 灯环显示模式（`FORWARD_SLOW`、`SIXSTAGE_BREATHING` 等，见 SDK 枚举）。

### 1.5 launch / SDK 可调参数

`unitree_lidar_ros2/launch/launch.py` 与节点参数（与 C++ `initialize()` 对应）：

| 参数 | 默认 | 说明 |
|------|------|------|
| `port` | `/dev/ttyUSB0` | 串口设备路径 |
| `rotate_yaw_bias` | `0.0` | 水平角偏置（度）；SDK v1.0.5 曾将出厂标定默认改为 `-38.5` |
| `range_scale` | `0.001` | 距离缩放 |
| `range_bias` | `0.0` | 距离偏置 |
| `range_max` / `range_min` | `50.0` / `0.0` | 有效量程（米） |
| `cloud_scan_num` | `18` | 拼帧线束数 |
| `cloud_topic` / `cloud_frame` | 见上 | 点云 topic / frame |
| `imu_topic` / `imu_frame` | 见上 | IMU topic / frame |

## 2. 接口定义（L1_Overview_Link）

### 2.1 4PIN 插头

- 出线：**GH1.25mm 4PIN** 串口座。
- 可用附带的**转接模块 + 12 V 电源适配器 + USB Type-C 数据线**实现电源 / 控制信号 / 数据传输。
- 也可**自行定制线材**替换转接模块，以提高整体防护性（如防尘、防水）。

### 2.2 4PIN 线序（官方定义）

| 脚位 | 信号 | 属性 | 描述 | 线色 | 功能 |
|------|------|------|------|------|------|
| 1 | **VCC** | 供电 | DC **12 V** 供电 | 红 | 电源线 |
| 2 | **GND** | GND | 地线 | 白 | 电源线 |
| 3 | **RX** | Input **3.3 V** | 测距核心**串口输入** | 绿 | 功能线 |
| 4 | **TX** | Output **3.3 V** | 测距核心**串口输出** | 黑 | 功能线 |

注意：

- 信号电平为 **3.3 V TTL**。若主机是 5 V TTL 或 RS-232 电平，需要**电平转换**（官方转接模块内含 USB-TTL 芯片，直连 PC/Jetson USB 时不用另接）。
- RX / TX 是**从雷达角度**：雷达 RX = 主机 TX；雷达 TX = 主机 RX。自制线材时不要接反。

连接步骤（官方快速入门）：

1. L1 的 4PIN 插入转接模块。
2. 电源适配器插入转接模块供电口（12 V）。
3. Type-C 数据线接转接模块与计算机（或 Jetson）。

### 2.3 串口权限（Linux / Jetson）

```bash
sudo usermod -a -G dialout $USER
# 重新登录后生效
```

无权限时打开串口会报 **Permission denied**。

### 2.4 本仓库：稳定串口别名

USB 设备名可能随插口变化。建议在 Jetson 用 udev 固定为 `/dev/unilidar_lidar`，详见 [jetson/README.md](../README.md)「固定串口别名」一节。

当前 mirror 中 `launch.py` 写的是 `/dev/unilidar_serial4`，**跑 demo 前必须改成实机存在的路径**。

## 3. 安装（L1_Overview_install）

### 3.1 安装尺寸

| 项 | 值 |
|----|----|
| 重量 | **230 g** |
| 尺寸（W × D × H） | **75 × 75 × 65 mm** |
| 安装孔 | 底部 **4×M3**，深度 **6 mm** |

按官方机械图纸对应的 M3 孔位规划安装板。

### 3.2 有效视场角（FOV）

L1 内部：

- **高速电机**：带动反光镜旋转，实现**竖直方向 180°** 范围测量。
- **低速电机**：带动测量核心 **360°** 旋转。

合成 **360° × 90° 半球形**超广角扫描，覆盖雷达**上方 360° 三维空间**。

注意：

- 点云密度**越靠近中心（雷达上方轴附近）越高**，边缘越稀。
- 安装时**不要遮挡 FOV 有效区域**。

### 3.3 安装注意事项（正式安装前必读）

1. 安装前用**酒精或清洁布**清洁光学窗口；使用中保持清洁，灰尘 / 污渍会显著影响扫描效果。
2. 不要遮挡 FOV；**即使在光学窗口上加透明玻璃板也会影响性能**。
3. 可通过底部安装孔**以任意方向**安装（正装 / 倒装 / 卧装均可）。
4. 安装结构**只保证雷达自身可靠性**，机身**不能承受额外负载**。
5. **四面预留空间**，保证空气流动散热。
6. 有防水需求时，需**外加防水保护装置**（正装与倒装的防护示意见官方文档；官方提供 [雷达防雨罩图纸](https://support.unitree.com/home/zh/L1_SDK/L1_Overview_install)，推荐**软胶材质 3D 打印**）。
7. 减振 / 配重：L1 内部有高速旋转电机和精密光学结构，运行时会有水平与竖直方向震动。若需减小**水平方向**震动，可在 L1 防护罩外壳上加 **5–6 g 配重**；但**竖直方向**震动幅度会随之增加，二者权衡。

### 3.4 实车安装注意（本仓库）

若 L1 **卧放**（非常见竖直姿态），RViz 里 `unilidar_lidar` 的轴向可能与直觉不一致（例如 Z 朝前）。  
**不要靠猜**：在 RViz 用 `Axes` 看清 X/Y/Z，再在静态 TF（`base_link → unilidar_lidar`）里补旋转。详见 [cockpit/README.md](../cockpit/README.md)。

第 3 条明确「任意方向安装」，因此卧放本身合法；只是 TF 需要正确补上安装旋转。

## 4. 使用与坐标系（L1_Overview_Use / 使用前准备）

### 4.1 坐标系定义（右手系，官方原文）

原点 **O** 位于底部中心位置，**O-XYZ** 为 L1 的点云坐标系：

- **+X**：出线口的**反方向**。
- **+Y**：+X 轴**逆时针旋转 90°**方向。
- **+Z**：垂直底面**向上**（右手系导出）。

IMU 坐标系 `unilidar_imu` 的 XYZ 与点云坐标系**相对平行**，原点在点云坐标系下的位置（米）：

```text
[-0.007698, -0.014655, 0.00667]
```

（IMU 原点及 XYZ 坐标系官方以 L1 3D 模型为准。）

### 4.2 点云数据内容（官方口径）

默认情况下，L1 **上电即输出点云数据**，点云数据中包括：

| 字段 | 说明 |
|------|------|
| 距离值 | 采样点之间的实际距离，单位 **mm** |
| 夹角 | 采样点相对于 L1 自身朝向的夹角，单位度 |
| 反射率 | 所探测物体的反射率 |
| IMU 数据 | 3 轴加速度 + 3 轴陀螺仪 |
| 工作状态 | 当前转速、电压、温度等 |

### 4.3 工作状态

L1 的**工作状态**指测距仪当前实际所处状态（观测量）：

| 状态 | 描述 |
|------|------|
| **采样状态** | 已启动、正常工作，发射激光束 |
| **待机状态** | 设置待机后进入，功耗 < 1 W，LED 熄灭，高/低速电机停转，**只输出 IMU 数据** |
| **干扰状态** | 外力强制停转后点云不可用；外力释放后自动恢复转动与点云输出 |

### 4.4 工作模式

**工作模式**是用户设定的目标工作状态。L1 支持两种：

- **正常模式（Normal）**：出厂默认；断电重上电恢复此模式。
- **待机模式（Standby）**：低功耗。

切换方式：**Unilidar 上位机** 或 **Unilidar SDK**（`setLidarWorkingMode(NORMAL/STANDBY)`）。

### 4.5 LED 模式

LED 灯环共 **8** 种模式：

`命令模式` / `正转慢速` / `正转快速` / `反转慢速` / `反转快速` / `三段翻转` / `三段呼吸` / **`六段呼吸`（出厂默认）**

- 使用 Unilidar 上位机时会自动切到 **命令模式**。
- 断电重上电后**保持上次使用的 LED 模式**。
- 命令模式下可逐灯自定义（每颗灯珠状态）；详见《Unilidar 用户手册》。

SDK 枚举（`unitree_lidar_sdk.h`）：

```cpp
enum LEDDisplayMode {
    FORWARD_SLOW=2,  FORWARD_FAST=3,
    REVERSE_SLOW=4,  REVERSE_FAST=5,
    TRIPLE_FLIP=6,   TRIPLE_BREATHING=7,
    SIXSTAGE_BREATHING=8,
};
```

### 4.6 Windows Unilidar 上位机（快速看云）

Unilidar 是一款可实时显示、解析三维点云的操作软件，并支持产品设置、外参调节等高级功能。**仅 Windows 64 位**。

1. 官网下载最新的驱动与 Unilidar（[www.unitree.com](https://www.unitree.com)）。
2. 解压，双击 **`CP210xVCPInstaller_x64`** 安装驱动。
3. **以管理员身份**运行 `Unilidar.exe`。
4. 展开串口列表，选前缀含 **Silicon** 的 COM 口 → 打开串口。
5. 右侧点云窗口，左侧设备管理窗口（状态 + 参数）。

> 上位机**仅做展示与配置**，不做数据处理 / 存储 / 导出。真实业务使用请走 SDK / ROS2。

source /opt/ros/humble/setup.bash

```

```

## 5. 二次开发（L1_develope）

### 5.1 前言（官方口径）

- **L1 仅为激光雷达传感器**，不具备智能分析、数据存储功能；实际场景应用需要二次开发。
- 上电正常工作后，L1 **持续发送**点云 + IMU 等数据。
- 官方 **Unilidar 上位机**（Windows）只做简单点云展示与参数配置，**不做**数据处理 / 存储 / 导出。
- **时间同步**：以「雷达完全启动后的时刻」为起始点，每包数据自带时间戳。

### 5.2 四种接入方式（Unilidar SDK）

| 方式 | 目录 | 适用 |
|------|------|------|

### 5.6 无 SDK 场景：MavLink 原始解析

L1 原始数据的通信协议为 **MavLink**。当开发环境无法使用 SDK 时，需要**逐字节**解析串口数据组帧。参考：

- [MavLink 官方入门](https://mavlink.io/en/getting_started/)
- 本仓库镜像：`jetson/mirror/ros2_ws/src/unitree_lidar_sdk/doc/HowToParsePointCloudAndIMUDataFromMavLinkMessages.md`

#### 5.6.1 IMU 数据（`mavlink_msg_ret_imu_attitude_data_packet.h`）

```c
typedef struct __mavlink_ret_imu_attitude_data_packet_t {
    float    quaternion[4];          // 四元数
    float    angular_velocity[3];    // xyz 角速度
    float    linear_acceleration[3]; // xyz 线加速度
    uint16_t packet_id;              // 帧 ID（判断连续性）
} mavlink_ret_imu_attitude_data_packet_t;
```

#### 5.6.2 点云：辅助包 + 距离包配对

两个头文件成对使用：

- `mavlink_msg_ret_lidar_auxiliary_data_packet.h` —— 反射率、角度起点、几何标定、脏污、温度…
- `mavlink_msg_ret_lidar_distance_data_packet.h` —— 距离信息（120 点，每点 2 字节小端）

配对依据：**两包 `packet_id` 相等**。`range == 0` 为无效点，需跳过。

关键辅助字段（节选）：

| 字段 | 含义 |
|------|------|
| `time_stamp_s_step` / `time_stamp_us_step` | 雷达运行时间戳（秒 + 微秒） |
| `sys_rotation_period` / `com_rotation_period` | 低速 / 高速电机转动周期（μs） |
| `com_horizontal_angle_start` / `_step` | 水平角起点 + 相邻点角度间隔 |
| `sys_vertical_angle_start` / `_span` | 垂直角起点 + 相邻数据角度跨度 |
| `apd_temperature` / `imu_temperature` | APD / IMU 温度 |
| `dirty_index` | 保护罩污垢指数 |
| `b_axis_dist` / `theta_angle` / `ksi_angle` | 激光标定（b、θ、ξ） |
| `reflect_data[120]` | 120 个点的反射率 |
| `payload_size` / `lidar_work_status` | 载荷大小 / 运行状态 |

距离包结构：

```c
typedef struct __mavlink_ret_lidar_distance_data_packet_t {
    uint16_t packet_id;
    uint16_t packet_cnt;
    uint16_t payload_size;
    uint8_t  point_data[240]; // 120 点 × 2 字节，小端
} mavlink_ret_lidar_distance_data_packet_t;
```

#### 5.6.3 距离 + 辅助 → 直角坐标（官方参考实现）

以下为官方 `parseRangeAuxiliaryDataToCloud` 的等价整理版。核心几何：`b, θ, ξ` 标定 + 水平/垂直角 + 距离 → XYZ；末尾附反射强度。

```cpp
bool parseRangeAuxiliaryDataToCloud(
    const mavlink_ret_lidar_auxiliary_data_packet_t& aux,
    const mavlink_ret_lidar_distance_data_packet_t&  rng,
    std::vector<std::array<float, 4>>&               scanCloud)
{
    if (aux.packet_id != rng.packet_id) return false;

    constexpr float rotate_yaw_bias = 0.0f;
    constexpr float range_scale     = 0.001f;   // mm -> m
    constexpr float z_bias          = 0.0445f;  // 基准面 Z 偏置
    constexpr int   N               = 120;
    const float bias_laser_beam     = aux.b_axis_dist / 1000.0f;

    const float sin_theta = std::sin(aux.theta_angle);
    const float cos_theta = std::cos(aux.theta_angle);
    const float sin_ksi   = std::sin(aux.ksi_angle);
    const float cos_ksi   = std::cos(aux.ksi_angle);

    float pitch_cur  = aux.sys_vertical_angle_start   * M_PI / 180.0f;
    float pitch_step = aux.sys_vertical_angle_span    * M_PI / 180.0f;
    float yaw_cur    = (aux.com_horizontal_angle_start + rotate_yaw_bias) * M_PI / 180.0f;
    float yaw_step   = aux.com_horizontal_angle_step / N * M_PI / 180.0f;

    for (int i = 0, j = 0; j < N;
         i += 2, j += 1, pitch_cur += pitch_step, yaw_cur += yaw_step)
    {
        uint16_t range = (rng.point_data[i + 1] << 8) | rng.point_data[i];
        if (range == 0) continue;              // 无效点
        const float r = range_scale * range;

        const float sin_a = std::sin(pitch_cur), cos_a = std::cos(pitch_cur);
        const float sin_b = std::sin(yaw_cur),   cos_b = std::cos(yaw_cur);

        const float A = (-cos_theta * sin_ksi + sin_theta * sin_a * cos_ksi) * r + bias_laser_beam;
        const float B =   cos_a * cos_ksi * r;

        std::array<float, 4> p;
        p[0] = cos_b * A - sin_b * B;                                            // x
        p[1] = sin_b * A + cos_b * B;                                            // y
        p[2] = ( sin_theta * sin_ksi + cos_theta * sin_a * cos_ksi) * r + z_bias;// z
        p[3] = aux.reflect_data[j];                                              // intensity
        scanCloud.push_back(p);
    }
    return true;
}
```

> 该函数是官方 SDK 内部逻辑的公开示例，本仓库不需要自己实现；只在完全脱离 SDK 时才用。

## 7. 参数规格（L1_Overview_specification）

L1 有两个型号：**L1 PM**（Precision Measurement，精测）和 **L1 RM**（Remote Measurement，远测）。除最大量程外，其它规格一致。

### 7.1 测距与光学

| 参数 | 规格 |
|------|------|
| 型号 | **L1 PM**（精测）/ **L1 RM**（远测） |
| 激光波长 | **905 nm** |
| 人眼安全等级 [1] | **Class 1**（IEC 60825-1:2014） |
| 最大量程 [2] | L1 PM：**20 m @90%** / **10 m @10%**<br>L1 RM：**30 m @90%** / **15 m @10%** |
| 近处盲区 [3] | **0.05 m** |
| FOV | **360° × 90°**（半球形） |
| 采样频率 | **43 200 点/秒** |
| 有效频率 | **21 600 点/秒** |
| 扫描方式 | 无接触无刷转镜扫描 |
| 4D 信息 | 3D 位置 + 1D 灰度 |
| 周向扫描频率 | **11 Hz**（低速电机，360° 水平） |
| 竖直扫描频率 | **180 Hz**（高速电机） |
| 测量精度 [4] | **±2.0 cm** |
| 测距分辨率 | **8 mm** |
| 抗强光能力 | **100 klux** |

### 7.2 通信

| 参数 | 规格 |
|------|------|
| 通信接口 | **TTL UART**（3.3 V，见 §2.2） |
| 通信波特率 | **2 000 000 bps** |

与本仓库对应：SDK `initialize()` 默认 `2000000`，`launch.py` 保留默认即可，不用改。

### 7.3 IMU

| 参数 | 规格 |
|------|------|
| IMU 采样率 | **1 kHz** |
| IMU 上报频率 | **250 Hz** |
| 姿态感知维度 | 3 轴加速度 + 3 轴陀螺仪 |

### 7.4 指示灯

| 参数 | 规格 |
|------|------|
| LED 灯环分辨率 | **1°** |
| LED 灯环刷新率 | **11 Hz** |

灯环显示模式在 §5 SDK 部分详列。

### 7.5 环境与供电

| 参数 | 规格 |
|------|------|
| 工作环境温度 [5] | **-10 ℃ ~ 60 ℃** |
| 存储环境温度 | **-20 ℃ ~ 60 ℃** |
| 防护等级 [6] | **IP54** |
| 功率 [7] | **6 W**（环境 25 ℃） |
| 工作电压 | **DC 12 V** |
| 尺寸 | **75 × 75 × 65 mm**（宽×深×高） |
| 重量 | **230 g** |

### 7.6 官方脚注（原文）

- **[1]** 激光器瞬时峰值功率 25 W，实际平均功率远低于此值，脉冲驱动，极短时间发射，达到 Class I 人眼安全等级。
- **[2]** 表中为典型值，实际量程受环境和目标反射率影响。
- **[3]** 0.05 m 处激光探测仪可输出点云，但精度无保证，**仅供参考**。
- **[4]** 测试条件：环境 25 ℃，目标反射率 90%，距离 15 m；不同反射率下个别点精度可能略有下降。
- **[5]** 高温/低温、强振动、大雾会小幅降低性能；长期高温工作会影响性能甚至损坏。建议加散热，外壳温度 ≤60 ℃；超温 L1 会告警，严重超温会停机。
- **[6]** 不同安装角度下 IP54 的实际防护差异较大，**请根据安装角度自行增加外部防护**；因安装或防护不当造成的损坏不在保修范围。
- **[7]** 稳定功率与峰值功率因环境不同而异。

### 7.7 对本仓库的落地含义

- **供电必须 12 V**：Jetson Orin Nano 的 USB / GPIO 供不了 L1，必须走随附电源适配器或额外 12 V DC-DC，**不要**从 Jetson USB 5 V 直接反供。
- **量程口径要用 90% 反射率那一列**：本项目跑的是 **L1 PM**（默认），实际户外/低反射目标可用范围会缩到 10 m 以内。定 point-LIO 参数时把 `range_max` 从默认 `50.0` 调到 **20~25 m** 更贴合真实精度上限（分开建议：室内 `10~15`，户外 `15~20`）。
- **热管理**：Jetson 外壳内部/风道薄的机型请保证 L1 外壳可散热，不要贴热源，避免触发过温停机。
- **IP54 不等于随便淋雨**：户外测试时按 §3.3 建议加外罩（软胶 3D 打印雨罩图纸官方有提供）。
- **点云统计**：43 200 点/秒总采样中有 21 600 点为**有效点**（另一半是遮挡/边缘/无效），实机看到的 topic 频率约 9~11 Hz、单帧点数与 `cloud_scan_num` 相关（默认 18 线，累计 ≈ 2 160 点/帧）。

## 9. 常见问题

| 现象 | 可能原因 | 处理 |
|------|----------|------|
| `Permission denied` 打开串口 | 未加入 `dialout` | `sudo usermod -a -G dialout $USER` 后重登 |
| launch 初始化失败 | `port` 与实机不符 | `ls /dev/tty*`、udev 别名、改 `launch.py` |
| WSL 看不到 topic | `ROS_DOMAIN_ID` 不一致或网络隔离 | 对齐 `.env`，检查防火墙 / 多网卡 |
| 点云方向与车体不符 | 卧放 / 静态 TF 未标定 | RViz 看轴，只改 `base_link→unilidar_lidar` 静态 TF |
| 点云稀疏或卡顿 | `cloud_scan_num`、USB 供电、主机负载 | 保持 12 V 供电，减少 Jetson 上无关重负载 |
