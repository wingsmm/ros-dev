# 远端小车登录说明

本文档只说明如何从 Windows 本机登录塔克小车，以及登录后如何连接 ROS 网络。硬件、话题和建图流程分别见 [远端硬件与传感器.md](./远端硬件与传感器.md) 与 [真机建图与遥控方案.md](./真机建图与遥控方案.md)。

## 1. 实测连接信息

| 项目 | 值 |
|------|-----|
| 主机名 | `xtark-robot` |
| IP | `192.168.1.169` |
| SSH 用户 | `xtark` |
| SSH 密码 | `xtark` |
| 系统 | Ubuntu 18.04.5 LTS / Jetson Nano / ROS Melodic |

登录前先确认 PC 与小车在同一局域网：

```powershell
ping 192.168.1.169
```

如果 IP 变化，以小车实际地址为准，后续命令中的 `192.168.1.169` 同步替换。

## 2. OpenSSH 登录（推荐）

在 PowerShell、CMD 或 Cursor 终端执行：

```powershell
ssh xtark@192.168.1.169
```

首次连接会要求确认主机指纹，输入 `yes` 后回车，再输入密码 `xtark`。

登录成功后通常能看到 ROS 环境提示，例如：

```text
ROS_MASTER_URI: http://192.168.1.169:11311
ROS_IP: 192.168.1.169
ROBOT TYPE: MEC
```

进入后建议先加载工作空间：

```bash
source /opt/ros/melodic/setup.bash
source ~/ros_ws/devel/setup.bash
```

## 3. PuTTY / plink

PuTTY 适合图形登录，`plink` 适合脚本里一次性执行命令。本机常见路径：

```text
C:\Program Files\PuTTY\plink.exe
```

当前小车主机密钥：

```text
ssh-ed25519 255 SHA256:hrGvBYXQfk9JH6fq71t0BYZEoulJ5WjZomhk5NlkLOY
```

PowerShell 一次性执行远程命令：

```powershell
$plink = "C:\Program Files\PuTTY\plink.exe"
$hostkey = "ssh-ed25519 255 SHA256:hrGvBYXQfk9JH6fq71t0BYZEoulJ5WjZomhk5NlkLOY"

& $plink -batch -hostkey $hostkey -pw xtark xtark@192.168.1.169 "hostname; uname -a"
```

交互式 plink 会话：

```powershell
& $plink -hostkey $hostkey -pw xtark xtark@192.168.1.169
```

说明：

| 参数 | 作用 |
|------|------|
| `-batch` | 非交互模式，避免脚本卡在提示上 |
| `-hostkey` | 固定主机密钥，避免首次连接确认 |
| `-pw xtark` | 传入密码；不要把含明文密码的脚本提交到公开仓库 |

## 4. 登录后的常用检查

```bash
source /opt/ros/melodic/setup.bash
source ~/ros_ws/devel/setup.bash

hostname
echo $ROBOT_TYPE
echo $LIDAR_TYPE
echo $ROS_IP
echo $ROS_MASTER_URI
```

启动驱动或建图后可检查 ROS 话题：

```bash
rostopic list
rostopic hz /scan
rostopic hz /odom
```

若提示 `Unable to communicate with master!`，通常只是还没有启动 `roscore` 或相关 launch。先启动 `xtark_bringup`、`xtark_slam` 或 `xtark_nav` 后再查。

## 5. PC 远程连接 ROS 网络

只有 SSH 不需要 PC 安装 ROS；但如果要在 PC 上运行 RViz 或直接发布 `/cmd_vel`，PC 侧需要 ROS Melodic 环境（如 WSL Ubuntu 18.04 或虚拟机），并设置：

```bash
export ROS_IP=<PC 的局域网 IP>
export ROS_MASTER_URI=http://192.168.1.169:11311
source /opt/ros/melodic/setup.bash
```

典型用途：

```bash
# PC 上只看 RViz，不重复启动小车驱动或 SLAM
rviz

# 验证能看到小车话题
rostopic list
rostopic hz /scan
```

键盘遥控最省事的做法仍是在第二个 SSH 终端里跑小车自带 `xtark_keyboard`。PC 直接遥控需要 PC 上也有 `xtark_ctl` 包：

```bash
export ROS_IP=<PC 的局域网 IP>
export ROS_MASTER_URI=http://192.168.1.169:11311
source /opt/ros/melodic/setup.bash
rosrun xtark_ctl xtark_twist_keyboard.py _speed:=0.15 _turn:=0.4
```

## 6. 常见问题

| 现象 | 处理 |
|------|------|
| `Connection closed` / 连不上 | 检查小车是否上电、网络是否同段、IP 是否变化 |
| `ping` 不通 | 检查 Wi-Fi/网线；必要时在小车本地确认 IP |
| 主机指纹变更警告 | 小车重装或 SSH 密钥变化后，删除 `C:\Users\<你>\.ssh\known_hosts` 中对应行再连 |
| 密码正确仍失败 | 确认用户名是全小写 `xtark` |
| PC RViz 看不到 `/scan` | 检查 PC 的 `ROS_IP` 是否为本机局域网 IP，`ROS_MASTER_URI` 是否指向 Nano |
| `rostopic list` 报 master 错误 | 先在小车上启动 `xtark_slam.launch` 或 `xtark_bringup.launch` |

## 7. 安全提示

- 默认密码 `xtark` 只适合实验内网；正式使用请修改密码并配置 SSH 公钥登录。
- 避免把 `plink -pw xtark` 这类命令写进共享脚本、提交记录或日志。
