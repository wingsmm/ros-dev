# 远端小车硬件与传感器说明

本文档基于 **2026-06-02** 对 `xtark@192.168.1.168` 的实机探测（`uname`、`lsusb`、`udev`、`ros_ws` 配置），描述当前小车的计算平台、底盘与传感器，便于开发与排障。

---

## 1. 计算与系统平台

| 项目 | 实测信息 |
|------|----------|
| 主控 | NVIDIA Jetson Nano Developer Kit |
| 内核 | `Linux 4.9.201-tegra`（aarch64） |
| 系统 | Ubuntu 18.04.5 LTS |
| ROS | Melodic（`/opt/ros/melodic`） |
| 主机名 | `xtark-robot` |
| 机型 | `ROBOT_TYPE=MEC`（麦克纳姆轮全向底盘） |
| 主工作空间 | `~/ros_ws` |
| 建图工作空间 | `~/cartographer_ws` |

---

## 2. 传感器与执行器总览

```
                    ┌──────────────── Jetson Nano ────────────────┐
                    │                                           │
  激光雷达 ──USB──► │  /dev/lidar → ttyUSB0    →  /scan         │
  (RPLidar XAS)     │                                           │
                    │  /dev/video0 (UVC)     →  RGB 相机设备     │
  RGB 相机 ──USB──► │                                           │
                    │  Orbbec Astra Pro USB  →  深度相机设备      │
  深度相机 ──USB──► │                                           │
                    │                                           │
  底盘+IMU+电量 ─UART► /dev/ttyTHS1  →  xtark_driver           │
  (STM32 下位机)    │         → /odom, /imu, /voltage …         │
                    └───────────────────────────────────────────┘
```

## 3. 各传感器详情

### 3.1 激光雷达（2D LiDAR）

| 项目 | 说明 |
|------|------|
| 环境变量 | `LIDAR_TYPE=XAS`（默认，可在 `~/.bashrc` 修改） |
| 驱动包 | `rplidar_ros`（`third_packages/rplidar_ros`） |
| 设备节点 | `/dev/lidar` → `ttyUSB0` |
| USB 芯片 | QinHeng HL-340（`1a86:7523`），udev 已映射为 `lidar` |
| 主要话题 | `/scan_raw` → 滤波后 **`/scan`** |
| Launch | `xtark_driver/launch/xtark_bringup.launch` 内按 `LIDAR_TYPE` 选择 |

**可选雷达型号**（改 `LIDAR_TYPE` 后需匹配硬件）：

| `LIDAR_TYPE` | 驱动 | 说明 |
|--------------|------|------|
| `XAS` | `rplidar_ros` | 当前小车配置（思岚 RPLidar 系列） |
| `XT1` | `sc_mini` | 蓝海光电等迷你雷达 |
| `YT1` | `sc_mini` | 另一安装位姿配置 |

激光相对底盘 TF（MEC + XAS）：`base_footprint` → `laser`，约 `(0.05, 0, 0.1)`，绕 Z 转 π。

---

### 3.2 IMU（惯性测量单元）

| 项目 | 说明 |
|------|------|
| 来源 | 底盘下位机经串口上传（非独立 USB IMU） |
| 坐标系 | `base_imu_link`（相对 `base_footprint` 约 `(-0.1, 0, 0.05)`） |
| 主要话题 | **`/imu`** |
| 输出 | `xtark_driver` 从串口反馈帧解析 IMU 与里程计，当前源码直接发布 `/imu` 与 `/odom` |
| 融合 | 如具体部署额外启用 `robot_pose_ekf`，则以对应 launch 为准；本文不把 EKF 作为固定链路 |

参数见 `xtark_driver/config/xtark_params.yaml` 中 `imu_frame: base_imu_link`。

---

### 3.3 视觉设备索引

| 设备 | 标识 | 当前用途 |
|------|------|----------|
| UVC RGB 相机 | `/dev/video0`，`Astra Pro FHD Camera` | Android / PC 当前看图主链路 |
| Orbbec Astra Pro 深度相机 | `2bc5:0403`、`2bc5:0502` | 独立深度设备，非 Android 默认栈 |

---

### 3.4 底盘、编码器与电量

| 项目 | 说明 |
|------|------|
| 运动学 | 麦克纳姆轮（MEC），URDF：`xtark_mecx1.urdf` |
| 下位机通信 | **`/dev/ttyTHS1`**，波特率 **115200** |
| 驱动节点 | `xtark_driver`（`xtark_driver/launch/xtark_bringup.launch`） |
| 里程计 | `/odom` |
| IMU | `/imu` |
| 四轮速度（调试） | `/xtark/avel`、`/xtark/bvel`、`/xtark/cvel`、`/xtark/dvel` |
| 电量 | **`/voltage`**（`std_msgs/Float32`） |
| 控制指令 | **`/cmd_vel`**（键盘：`xtark_ctl/xtark_keyboard`） |

下位机为塔克 OpenCTR / STM32 方案，固件通过串口与 Jetson 交换里程计、IMU、电机 PID 等数据。历史键盘遥控与建图流程见 [archive/真机建图与遥控方案.md](./archive/真机建图与遥控方案.md)。

## 4. USB / 设备节点速查

实机 `lsusb` 摘要：

| USB ID | 设备 |
|--------|------|
| `1a86:7523` | CH340 串口 → 激光雷达 `/dev/lidar` |
| `2bc5:0403` | Orbbec ASTRA Pro |
| `2bc5:0502` | Orbbec 相关设备 |
| `8087:0a2b` | Intel 蓝牙 |

常用设备文件：

```text
/dev/ttyTHS1     # 底盘 + IMU（UART）
/dev/lidar       # 激光雷达（→ ttyUSB0）
/dev/video0      # UVC RGB 相机
```

---

## 5. ROS 话题速查（驱动启动后）

启动 `roslaunch xtark_driver xtark_bringup.launch` 后，常见话题包括：

| 话题 | 类型 / 用途 |
|------|-------------|
| `/scan` | `sensor_msgs/LaserScan`，导航与 SLAM |
| `/imu` | `sensor_msgs/Imu` |
| `/odom` | `nav_msgs/Odometry` |
| `/cmd_vel` | `geometry_msgs/Twist` |
| `/voltage` | 电池电压 |
| `/image_raw`、`/camera/image_raw` | UVC RGB 相机（需单独 launch camera） |

自检脚本：`rosrun xtark_driver self_check.py`（检查 IMU、四轮速度、电压等）。

## 6. 快速探测命令

SSH 登录方式见 [远端登录.md](./远端登录.md)。登录并加载 ROS 环境后，可用下面命令快速确认硬件与话题：

```bash
# 设备与 USB
lsusb
ls -l /dev/lidar /dev/ttyTHS1 /dev/video0

# ROS（需已 source 且 master 在运行）
source /opt/ros/melodic/setup.bash
source ~/ros_ws/devel/setup.bash
rostopic list
rostopic hz /scan
rostopic echo /imu -n 1
```
