# 真机自主导航方案

本文档说明 **塔克 MEC 小车（xtark-robot）** 在 **已有地图** 基础上的自主导航流程：定位（AMCL）→ 路径规划 → 运动控制 → 自动到达目标点。对应 Bilibili 教程 [【开源】超低成本的激光雷达导航方案！](https://www.bilibili.com/video/BV15Li4B9EDW/) 中 **6.jpg 导航架构图**（地图服务器 + AMCL + 规划器 + 控制器 + 恢复行为）。

**前置**：须先完成建图并保存 `map.pgm` + `map.yaml`，见 [真机建图与遥控方案.md](./真机建图与遥控方案.md)。

相关文档：[真机建图与遥控方案.md](./真机建图与遥控方案.md) · [远端硬件与传感器.md](../远端硬件与传感器.md) · [远端登录.md](../远端登录.md)

## 1. 建图 vs 导航（两阶段）

| | 建图（SLAM） | 自主导航（本方案） |
|--|-------------|-------------------|
| 目标 | 生成环境地图 | 在已知地图里自动走到目标 |
| 地图 | **输出** `/map` → 存文件 | **输入** 加载 `map.yaml` |
| 控车方式 | **你遥控**（`/cmd_vel` 手动） | **move_base 自动**发 `/cmd_vel` |
| 本车 launch | `xtark_slam.launch` | **`xtark_nav.launch`** |
| 核心算法 | gmapping / cartographer | **AMCL + move_base + TEB** |

```
建图 ──map_saver──► map.pgm/yaml ──map_server──► 自主导航（可反复使用）
```

## 2. 系统架构（对照教程导航图）

```
map.pgm + map.yaml
       ↓
┌──────────────┐     /map      ┌─────────┐     定位 TF      ┌──────────────┐
│ map_server   │ ────────────► │  AMCL   │ ───────────────► │  move_base   │
└──────────────┘               └────▲────┘                  │  (TEB 规划)  │
                                  │                         └──────┬───────┘
  /scan ◄── rplidar_ros ──────────┤                                │
  /odom ◄── xtark_driver+EKF ─────┘                                ▼
                                                            /cmd_vel → 底盘
```

| 教程模块（6.jpg） | 本车实现 | ROS 包/节点 |
|-------------------|----------|-------------|
| 地图文件 `map.pgm/yaml` | `~/ros_ws/src/xtark_nav/maps/` | — |
| 地图服务器 | `map_server` | `map_server` |
| 雷达消息 | `/scan` | `rplidar_ros` + 滤波 |
| AMCL 定位器 | `amcl_omni.launch`（MEC 全向） | `amcl` |
| 路径规划 + 控制 | `teb_move_base_omni.launch` | `move_base` + **TEB** |
| 导航恢复行为 | move_base 内置 recovery | `move_base` |
| 速度平滑 | TEB / move_base 参数 | `teb_local_planner` |
| 底盘执行 | `xtark_driver` | 订阅 `/cmd_vel` |

教程为 **ROS2 Nav2**；本车为 **ROS1 move_base + TEB**，流程等价。

## 3. `xtark_nav.launch` 启动了什么

小车 `~/ros_ws/src/xtark_nav/launch/xtark_nav.launch` 依次启动：

| 顺序 | 组件 | 作用 |
|------|------|------|
| 1 | `xtark_bringup.launch` | 底盘、雷达、EKF、TF |
| 2 | `xtark_camera.launch` | UVC 相机（可选，不影响纯激光导航） |
| 3 | **`map_server`** | 加载地图 yaml，发布 `/map` |
| 4 | **`amcl_omni`**（MEC） | 粒子滤波定位，`map`→`odom` TF |
| 5 | **`teb_move_base_omni`** | 全局/局部规划，发布 `/cmd_vel` |
| 6 | `rosbridge` + APP 辅助节点 | 手机设目标点、取消任务等 |

**默认地图**：

```xml
<arg name="map_file" default="$(find xtark_nav)/maps/xtark_test.yaml"/>
```

已有示例地图：`xtark_test`、`test1`、`office`（均在 `maps/` 目录）。

**MEC 与 4WD 分支**：由环境变量 `ROBOT_TYPE` 决定（本车为 `MEC` → `amcl_omni` + `teb_move_base_omni`）。

## 4. 前置条件

### 4.1 必须有可用地图

```bash
# 地图目录（Nano 上）
ls ~/ros_ws/src/xtark_nav/maps/
# 应成对存在：xxx.pgm + xxx.yaml
```

若还没有，先按 [真机建图与遥控方案.md](./真机建图与遥控方案.md) 建图并：

```bash
rosrun map_server map_saver -f ~/ros_ws/src/xtark_nav/maps/my_room
```

### 4.2 硬件与驱动（同建图）

| 检查 | 命令/期望 |
|------|-----------|
| 雷达 | `rostopic hz /scan` 有数据 |
| 里程计 | `rostopic hz /odom` 有数据 |
| 环境变量 | `ROBOT_TYPE=MEC`，`LIDAR_TYPE=XAS` |

### 4.3 环境与地图一致

- 导航用的地图必须是 **当前环境** 建的；家具大改、换房间需 **重新建图**。
- 启动时机器人应放在 **地图范围内**，且大致位置正确（见 §6 初始位姿）。

## 5. 真机操作流程

### Step 1：启动导航（Nano）

**使用默认地图 `xtark_test.yaml`：**

```bash
ssh xtark@192.168.1.168
source /opt/ros/melodic/setup.bash
source ~/ros_ws/devel/setup.bash
roslaunch xtark_nav xtark_nav.launch
```

**指定自己的地图：**

```bash
roslaunch xtark_nav xtark_nav.launch \
  map_file:=$(rospack find xtark_nav)/maps/my_room.yaml
```

**指定初始位姿（若 AMCL 收敛慢）：**

```bash
roslaunch xtark_nav xtark_nav.launch \
  map_file:=$(rospack find xtark_nav)/maps/my_room.yaml \
  initial_pose_x:=1.0 initial_pose_y:=2.0 initial_pose_a:=0.0
```

### Step 2：RViz 中设定位与目标

**方案 A — Nano 本地 / VNC RViz**

```bash
rosrun rviz rviz
```

配置建议：

| 项 | 设置 |
|----|------|
| Fixed Frame | **`map`** |
| Map | Topic: `/map` |
| LaserScan | Topic: `/scan` |
| TF | 开启 |
| Pose Estimate | 工具栏 **2D Pose Estimate** — 在地图上点机器人 **实际位置+朝向** |
| Nav Goal | 工具栏 **2D Nav Goal** — 点 **目标位置+朝向** |

**方案 B — PC 远程 RViz**（WSL Melodic）

```bash
export ROS_IP=<PC IP>
export ROS_MASTER_URI=http://192.168.1.168:11311
source /opt/ros/melodic/setup.bash
rviz
# 同上配置；2D Pose Estimate / 2D Nav Goal 在 PC 上点击即可
```

### Step 3：观察自动行走

- AMCL 粒子收敛后，绿色粒子云与激光轮廓应对齐。
- 发送 Nav Goal 后，`move_base` 规划路径，底盘自动发 `/cmd_vel`。
- RViz 中可见全局路径（`/move_base/NavfnROS/plan` 或 TEB 相关 topic，视配置而定）。

### Step 4：停止 / 取消目标

- RViz 取消或官方 APP 取消（`xtark_cancelGoalListen` 节点已随 launch 启动）。
- 或：`rostopic pub /move_base/cancel actionlib_msgs/GoalID "{}"`

## 6. 初始定位（AMCL）要点

AMCL 需要知道机器人在地图上的 **大致位置**：

1. **推荐**：RViz **2D Pose Estimate** 点一下实际位置（比 launch 参数 `initial_pose_*` 更直观）。
2. 观察 `/scan` 与地图墙是否重合；粒子云应逐渐收敛。
3. 若定位飘移：
   - 重新 Pose Estimate
   - 检查地图是否过期、环境是否变化
   - 慢速移动一小段帮助 AMCL 更新

MEC 使用 **`odom_model_type: omni-corrected`**（全向运动模型），与麦轮匹配。

## 7. 关键话题与服务

| 话题/服务 | 用途 |
|-----------|------|
| `/map` | 静态地图（map_server） |
| `/scan` | 激光，AMCL + costmap 用 |
| `/odom` | 里程计 |
| `/cmd_vel` | move_base 输出，xtark_driver 执行 |
| `/move_base/goal` | 导航目标（action） |
| `/move_base/cancel` | 取消导航 |
| `/amcl_pose` | 当前估计位姿 |

检查 move_base 是否正常：

```bash
rostopic echo /move_base/status
rosnode info /move_base
```

## 8. TF 树（导航阶段）

```
map  ──(AMCL 发布)──►  odom  ──(里程计)──►  base_footprint  ──►  laser
```

- **建图时**：gmapping 发布 `map→odom`。
- **导航时**：**AMCL** 发布 `map→odom`；`odom→base_footprint` 仍来自里程计。

Fixed Frame 在 RViz 中应设为 **`map`**。

## 9. 配置文件位置（调参参考）

MEC 全向导航参数目录：`~/ros_ws/src/xtark_nav/config/omni/`

| 文件 | 内容 |
|------|------|
| `costmap_common_params.yaml` | 代价地图通用（障碍层、膨胀半径等） |
| `local_costmap_params.yaml` | 局部代价地图 |
| `global_costmap_params.yaml` | 全局代价地图 |
| `teb_local_planner_params.yaml` | TEB 局部规划（速度、加速度、麦轮运动学） |
| `move_base_params.yaml` | 规划频率、恢复行为等 |
| `base_global_planner_param.yaml` | 全局规划器（Navfn/Dijkstra 等） |

定位参数：`launch/include/amcl_omni.launch`。

## 10. Nano 导航 + PC 监控

与建图阶段相同：Nano 运行所有驱动、定位和规划节点，PC 只连 ROS Master 做 RViz 显示和目标点交互。PC 远程 ROS 网络设置见 [远端登录.md](../远端登录.md)。

| 位置 | 运行内容 |
|------|----------|
| **Nano** | `xtark_nav.launch`（驱动 + map_server + AMCL + move_base） |
| **PC** | 仅 `rviz`（2D Pose Estimate + 2D Nav Goal） |

PC **不需要**再启动 map_server 或 move_base，否则会冲突。

## 11. 排障

| 现象 | 可能原因 | 处理 |
|------|----------|------|
| 车不动 | 未发 Nav Goal / move_base 未就绪 | 检查 `/move_base/status`；先 Pose Estimate |
| 定位不准 | 初始位姿错、地图旧 | 2D Pose Estimate 重设；重新建图 |
| 规划失败 `Goal unreachable` | 目标在障碍内或地图外 | 换目标点；检查 costmap |
| 乱撞 / 不避障 | `/scan` 异常、costmap 参数 | `rostopic hz /scan`；调 inflation_radius |
| TF 错误 | AMCL 未收敛 | 等粒子收敛或重设位姿 |
| 用了错地图 | 默认 `xtark_test` 非你的环境 | `map_file:=.../my_room.yaml` |
| 教程 Nav2 跑不起来 | 本车是 ROS1 move_base | 用 `xtark_nav.launch`，勿照搬 ROS2 |
