# 真机建图与遥控方案

本文档是塔克 MEC 小车（`xtark-robot`）做 **2D 激光建图、遥控扫图、保存地图** 的主流程。建图硬件链路、Nano/PC 分工、键盘遥控都收在这里，避免多个文档来回跳。

相关文档：

- [远端登录.md](./远端登录.md)：SSH、plink、PC 连接 ROS 网络
- [远端硬件与传感器.md](./远端硬件与传感器.md)：Jetson、雷达、底盘、相机、话题清单
- [真机自主导航方案.md](./真机自主导航方案.md)：已有地图后的 AMCL + move_base 导航

## 1. 一句话结论

本车不要直接套 B 站教程里的 ROS2 `lidar_pkg` / `wpr_simulation2`。硬件和 ROS 版本不同，但数据流一致：

```text
雷达 /scan + 底盘 /odom + TF -> gmapping/cartographer -> /map -> RViz -> map_saver
```

本车直接使用官方 ROS1 栈：

```bash
roslaunch xtark_nav xtark_slam.launch
```

这条命令会启动底盘、雷达、EKF、TF、相机、gmapping 以及 APP 相关 rosbridge。

## 2. 教程与本车对照

| 教程/示意图 | 本车实现 | 说明 |
|-------------|----------|------|
| ROS2 | **ROS1 Melodic** | 不要直接拷 ROS2 launch |
| `lidar_pkg` | **`rplidar_ros`** | 当前雷达是思岚 RPLidar XAS |
| `d1_bringup` | **`xtark_driver`** | 负责底盘、里程计、IMU、`/cmd_vel` |
| SLAM Toolbox | **gmapping**（默认）/ cartographer | 入门先用 gmapping |
| RViz2 | **RViz** | 可在 Nano 或 PC 上运行 |
| `slam_robot` | `xtark_slam.launch` | 在 Jetson Nano 上跑 |
| `slam_pc` | PC 上只跑 `rviz` | 不启动雷达驱动或 SLAM |

## 3. 系统分工

```text
Jetson Nano（192.168.1.169，ROS Master）
  /dev/lidar   -> rplidar_ros + laser_filters -> /scan
  /dev/ttyTHS1 -> xtark_driver + EKF          -> /odom /imu
  TF           -> odom -> base_footprint -> laser
  gmapping     -> /map
  cmd_vel      <- 键盘 / APP / 导航

PC（可选）
  rviz         -> 订阅 /map /scan /tf
  键盘遥控     -> 可选，需 PC 有 ROS Melodic + xtark_ctl
```

必须在 Nano 上运行：雷达驱动、底盘驱动、SLAM。PC 只负责显示或远程发控制话题。

## 4. 建图前检查

### 4.1 登录

```powershell
ssh xtark@192.168.1.169
```

登录和 plink 详见 [远端登录.md](./远端登录.md)。

### 4.2 加载环境

```bash
source /opt/ros/melodic/setup.bash
source ~/ros_ws/devel/setup.bash
```

`.bashrc` 中应有：

```bash
export ROBOT_TYPE=MEC
export LIDAR_TYPE=XAS
export ROS_IP=192.168.1.169
export ROS_MASTER_URI=http://$ROS_IP:11311
```

### 4.3 硬件快速确认

```bash
ls -l /dev/lidar /dev/ttyTHS1 /dev/video0
```

| 检查项 | 期望 |
|--------|------|
| `/dev/lidar` | 指向雷达 USB 串口，通常为 `ttyUSB0` |
| `/dev/ttyTHS1` | 底盘串口存在 |
| 雷达 | 上电后旋转 |
| 网络 | PC 能 ping 通小车 IP |

## 5. 推荐流程：单机建图

这是第一次验证时最稳的流程，所有核心节点都在 Nano 上。

### 终端 1：启动建图

```bash
ssh xtark@192.168.1.169
source /opt/ros/melodic/setup.bash
source ~/ros_ws/devel/setup.bash
roslaunch xtark_nav xtark_slam.launch
```

等待雷达旋转、终端无持续报错。

### 终端 2：键盘遥控

```bash
ssh xtark@192.168.1.169
source /opt/ros/melodic/setup.bash
source ~/ros_ws/devel/setup.bash
roslaunch xtark_ctl xtark_keyboard.launch
```

建图时建议慢速。也可以直接用降速参数：

```bash
rosrun xtark_ctl xtark_twist_keyboard.py _speed:=0.15 _turn:=0.4
```

键盘遥控发布 `/cmd_vel`，脚本位置为 `~/ros_ws/src/xtark_ctl/scripts/xtark_twist_keyboard.py`。不要用教程里的 `wpr_simulation2/keyboard_vel_cmd`，那是 ROS2 仿真包。

普通模式按键：

| 键 | 动作 |
|----|------|
| `i` | 前进 |
| `,` | 后退 |
| `j` / `l` | 左转 / 右转 |
| `u` / `o` | 前进 + 左/右转 |
| `m` / `.` | 后退 + 左/右转 |
| `k` / 空格 | 停车 |
| `Ctrl+C` | 退出并停车 |

麦轮横移需要按住 `Shift`：

| 键 | 动作 |
|----|------|
| `Shift+I` | 向前 |
| `Shift+J` | 向左平移 |
| `Shift+L` | 向右平移 |
| `Shift+<` | 向后 |

调速键：

| 键 | 作用 |
|----|------|
| `q` / `z` | 线速度和角速度同时放大 / 缩小 |
| `w` / `x` | 仅线速度放大 / 缩小 |
| `e` / `c` | 仅角速度放大 / 缩小 |

建图时建议先按几次 `x` 和 `c` 降速。注意：教程里的 `W/A/S/D/Q/E` 布局与本车不同，本车 `q/w/e` 是调速，不是转向。

### 终端 3：验证话题或保存地图

建图过程中可检查：

```bash
rostopic hz /scan
rostopic hz /odom
rostopic echo /cmd_vel
```

地图满意后保存：

```bash
rosrun map_server map_saver -f ~/ros_ws/src/xtark_nav/maps/my_room
```

会生成：

```text
my_room.pgm
my_room.yaml
```

## 6. PC 远程 RViz

PC 只看地图时，不需要在 PC 上启动驱动或 SLAM。

Nano 仍然运行：

```bash
roslaunch xtark_nav xtark_slam.launch
```

PC（WSL Ubuntu 18.04 / ROS Melodic）设置：

```bash
export ROS_IP=<PC 的局域网 IP>
export ROS_MASTER_URI=http://192.168.1.169:11311
source /opt/ros/melodic/setup.bash
rviz
```

RViz 设置：

| 项 | 设置 |
|----|------|
| Fixed Frame | `map` |
| Map | Topic: `/map` |
| LaserScan | Topic: `/scan` |
| TF | 开启 |

验证 PC 已连上小车 Master：

```bash
rostopic list
rostopic hz /scan
```

Windows/PC 没有 ROS 时，用第二个 SSH 终端在 Nano 上跑键盘，RViz 可改用 Nano 本地显示器或 VNC。

## 7. 分阶段验收

### 阶段 1：仅驱动

```bash
roslaunch xtark_driver xtark_bringup.launch
```

另开终端：

```bash
source /opt/ros/melodic/setup.bash
source ~/ros_ws/devel/setup.bash
rostopic hz /scan
rostopic hz /odom
rostopic echo /imu -n 1
```

通过标准：`/scan`、`/odom`、`/imu` 均有稳定数据；手动推车时 `/scan` 轮廓变化。

### 阶段 2：遥控底盘

保持 `xtark_bringup` 运行，另开终端：

```bash
roslaunch xtark_ctl xtark_keyboard.launch
```

车能低速前进、转向、停车后，再进入建图。

### 阶段 3：建图

```bash
roslaunch xtark_nav xtark_slam.launch
```

RViz 中 `/map` 应随移动扩展，墙体轮廓应逐渐闭合。

### 阶段 4：保存并导航验证

```bash
rosrun map_server map_saver -f ~/ros_ws/src/xtark_nav/maps/my_room
roslaunch xtark_nav xtark_nav.launch map_file:=$(rospack find xtark_nav)/maps/my_room.yaml
```

导航流程见 [真机自主导航方案.md](./真机自主导航方案.md)。

## 8. 建图技巧

- 速度控制在 `0.05~0.15 m/s`，拐角处更慢。
- 尽量走闭环，让地图有机会回到已知位置。
- 避免长时间原地猛转、打滑、快速横移。
- 玻璃墙、长空旷走廊、动态人群会降低建图质量。
- gmapping 主要依赖 `/scan`、`/odom` 和 TF；先保证底层稳定，再调算法。

## 9. 常用 launch

| 用途 | 命令 |
|------|------|
| 仅底盘 + 雷达 + EKF | `roslaunch xtark_driver xtark_bringup.launch` |
| 仅雷达 | `roslaunch xtark_driver xtark_lidar.launch` |
| 建图，默认 gmapping | `roslaunch xtark_nav xtark_slam.launch` |
| 指定 gmapping | `roslaunch xtark_nav xtark_slam.launch slam_methods:=gmapping` |
| 指定 cartographer | `roslaunch xtark_nav xtark_slam.launch slam_methods:=cartographer` |
| 键盘遥控 | `roslaunch xtark_ctl xtark_keyboard.launch` |
| 导航 | `roslaunch xtark_nav xtark_nav.launch map_file:=...` |

cartographer 需要额外 source：

```bash
source ~/cartographer_ws/install_isolated/setup.bash
source ~/ros_ws/devel/setup.bash
```

入门阶段先用 gmapping。

## 10. `lidar_pkg_ros1` 决策

当前小车使用思岚 RPLidar XAS，走 `rplidar_ros`。本地或教程中的 `lidar_pkg_ros1` 面向扫地机拆机雷达，协议、波特率、USB 设备都不同。

| 方案 | 结论 |
|------|------|
| 保持当前雷达 | 推荐，继续用 `rplidar_ros` |
| 更换为教程雷达 | 需要换硬件、udev、launch 分支 |
| 不换硬件强行用 `lidar_pkg` | 不可行 |

## 11. 排障

| 现象 | 处理 |
|------|------|
| `Unable to communicate with master` | 先启动 `xtark_bringup`、`xtark_slam` 或 `roscore` |
| 无 `/scan` | 查 `/dev/lidar`，重插雷达 USB，确认 `LIDAR_TYPE=XAS` |
| 无 `/odom` | 查 `/dev/ttyTHS1`、底盘供电和 `xtark_driver` 日志 |
| 键盘按了车不动 | `rostopic echo /cmd_vel`；确认驱动已启动，终端焦点在键盘窗口 |
| PC RViz 看不到 map | 检查 PC `ROS_IP` 和 `ROS_MASTER_URI`，确认 Nano 正在运行 SLAM |
| 地图不扩展 | 车没动、gmapping 没收到 `/scan`，或 TF 不完整 |
| 地图漂移 | 降速，检查里程计标定和地面打滑 |
| 键位和教程不一致 | 正常；本车用 `i/j/k/l`，`q/w/e` 是调速 |
| 教程代码跑不起来 | 正常；本车是 ROS1，不直接运行 ROS2 教程 launch |

## 12. 第一次建图 Checklist

- [ ] SSH 能登录小车
- [ ] `/dev/lidar`、`/dev/ttyTHS1` 存在
- [ ] `xtark_bringup` 下 `/scan`、`/odom`、`/imu` 正常
- [ ] `xtark_keyboard` 或 APP 能控车
- [ ] `xtark_slam.launch` 启动无持续报错
- [ ] RViz 中 `/map` 随移动增长
- [ ] 慢速走闭环
- [ ] `map_saver` 保存 `pgm/yaml`
- [ ] 用保存地图启动 `xtark_nav.launch` 做导航验证
